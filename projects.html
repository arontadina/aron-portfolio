A Community-Based Post-Disaster Recovery Monitoring Platform

Mobile-first web appWeb developmentDeployed on Vercel

BalikBarangay is a community-based post-disaster recovery monitoring platform. It works as a tracking system for the recovery and rehabilitation of a barangay after a calamity, and it is built mobile-first so it can be used on the phones people already carry. I built it end to end, and it is live now.
